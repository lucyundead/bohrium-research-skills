# 静默错误检查表

执行成功只证明进程结束。交付前逐项核对，并把异常写入 `uncertainty` 或质量报告。

## 输入与字段

- [ ] `case_id`、字段名和类型来自实际 `case.json`，不是从任务标题猜出。
- [ ] 文件 SHA-256 已记录；分析前后原始输入未变化。
- [ ] CSV 分隔符、编码、表头、引号、尾部空行经过实际检查。
- [ ] SQLite 只读打开，表名、列类型、行数与查询目标一致。
- [ ] 字段前后空白、同义字段和单位映射有明确规则。
- [ ] 没有按数据集名称假设版本、行数或内容。

## 缺失、审查值与重复

- [ ] 真正缺失、空字符串、`?`、`NA`、`N/A`、`null` 分开计数。
- [ ] `<0.01` 等审查值未被当成精确值或 0；所用替代规则有任务依据。
- [ ] 缺失值没有静默变成 0 后进入均值、分母或模型。
- [ ] 重复行只被标记；是否去重由实验单位和任务规则决定。
- [ ] 去重前后行数、分组样本量和结果变化已记录。
- [ ] 常数/零方差列已标记；零方差相关系数为未定义而非 0。

## 统计与查询

- [ ] 每个关键数字可由原始输入、过滤条件和公式独立复算。
- [ ] pandas 与 SQLite 对账覆盖全部数值列及任务关键过滤查询。
- [ ] SQL `COUNT(*)` 与 `COUNT(column)` 的 NULL 差异已核对。
- [ ] SQL 空集 `SUM/AVG` 与 pandas 默认行为差异已核对。
- [ ] 分组、连接和过滤后行数符合预期；没有扇出或漏条件。
- [ ] 整数除法、浮点求和顺序、时区、单位和有效数字没有暗中改变口径。
- [ ] IQR/Z-score 离群值仅标记；任何排除都有理由并报告样本量。
- [ ] 检验/模型前提、独立性和样本量已检查；不强行给 p 值。
- [ ] 空查询和失败查询保留 SQL、错误及下游影响，没有手填结果。
